## 神经网络解剖教室 v1.0.0 🎓

一个**纯静态网页**：在浏览器里手写数字，亲眼看着 169→16→10 的全连接网络做前向传播、反向训练，并在测试集上评估泛化。**零 npm 依赖、零后端**——本地起个静态服务即用。

### 玩法

1. **像素化**——左边画板手写数字，看它被压缩成 13×13 输入
2. **前向传播**——点「▶ 推理」，信号粒子流过 16 个隐藏节点，输出 10 个概率柱
3. **训练**——点「保存并训练」：红色误差粒子反向流动，权重边泛起脉冲，对比更新前后
4. **泛化**——一键导入示例数据集（1000 训练 / 300 测试），训练 15 轮后看准确率、每类准确率、10×10 混淆矩阵；点格子可查看错分样本原图、删除错标

- 点击隐藏节点查看它 169 个输入权重的热力图
- 工作区是**真实文件夹**（File System Access API）：`samples/` 存手写 PNG + manifest，`models/` 存 `.nnmodel.json`（含 Adam 优化器状态），换电脑拷走即迁移
- 可复现训练：固定 seed 的 shuffle 序列 bit-identical，暂停/继续不断 Adam 状态

### 技术要点

- 引擎：169→16→10 MLP，LeakyReLU(0.01) + Softmax + Adam，纯 ES Modules
- 渲染：Canvas 2D 纯数学粒子系统，无 DOM 粒子
- 260×260 → 居中 → 13×13 → 归一化预处理；数值约定"墨=1"
- 测试：52 逻辑单测 + 8 端到端 + 8 UI 走查，全部通过

### 运行

- **Mac**：双击 `tools/serve.command`
- 任意系统：`python3 -m http.server 8080`，浏览器打开 `http://127.0.0.1:8080/index.html`
- 需要 **Chromium 内核**浏览器（Chrome/Edge），Firefox/Safari 不支持 `showDirectoryPicker`

### 已知限制

- 16 个隐藏单元很小，示例数据集准确率与初始化 seed 相关（E2E 用 seed=23，15 轮 Adam ≈ 0.90）；日常多试几次或多训几轮
