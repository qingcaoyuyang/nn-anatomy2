# 神经网络解剖教室 v1.0.0 🎓

一个**纯静态网页**：在浏览器里手写数字，亲眼看着 3600→32→10 的全连接网络做前向传播、反向训练，并在测试集上评估泛化。**零 npm 依赖、零后端**——本地起个静态服务即用。

## 玩法

1. **手写**——左边画板手写数字，看它被预处理成 60×60 灰度输入
2. **前向传播**——信号流过 32 个隐藏节点（点击圆圈看每个节点的 60×60 权重热力图），输出 10 个概率柱
3. **训练**——3000 张训练样本，Adam 优化 15 轮，亲眼看着权重从噪点长出结构
4. **泛化**——300 张测试集看准确率（93.00%）、每类准确率、10×10 混淆矩阵；点格子可查看错分样本原图

- 工作区是**真实文件夹**（File System Access API）：`samples/` 存手写 PNG + manifest，`models/` 存模型 JSON（含 Adam 优化器状态），换电脑拷走即迁移
- 可复现训练：固定 seed 的 shuffle 序列，暂停/继续不断 Adam 状态

## 课堂 7 步演示流

1. 空模型展示权重（He 初始化随机小数，知识为零）
2. 0–9 各一张训练，看权重变化
3. 极小模型下手写测试 + 测试集测试（预期命中率很低）
4. 一键导入全量 3000 张训练
5. 打开权重页看变化
6. 再跑测试集，看命中率大幅提升
7. 手写数字逐笔实时预测

## 技术要点

- 引擎：3600→32→10 MLP（115,562 个参数），LeakyReLU(0.01) + Softmax + Adam(lr=0.001)，纯 ES Modules
- 60×60 灰度输入，重心居中预处理；数值约定"墨=1"
- 测试：54 个逻辑单测全部通过 + 8 步端到端走查

## 运行

- **Mac**：双击 `tools/serve.command`
- 任意系统：`python3 -m http.server 8080`，浏览器打开 `http://127.0.0.1:8080/index.html`
- 需要 **Chromium 内核**浏览器（Chrome/Edge），Firefox/Safari 不支持 `showDirectoryPicker`
